# Cách đưa portfolio này lên GitHub

1. Vào GitHub và chọn **New repository**.
2. Đặt tên repo: `embedded-hardware-portfolio`.
3. Chọn **Public** để HR có thể mở link mà không cần đăng nhập.
4. Không cần tick tạo README vì package này đã có sẵn `README.md`.
5. Sau khi tạo repo, chọn **Add file → Upload files**.
6. Kéo toàn bộ nội dung bên trong thư mục package lên GitHub: `README.md`, thư mục `assets`, thư mục `docs`.
7. Commit với nội dung: `Initial embedded hardware portfolio`.
8. Mở repo ở chế độ ẩn danh để kiểm tra ảnh và PDF hiển thị được.
9. Dán link repo vào ô **Profile/Portfolio** của form ứng tuyển.

Gợi ý tên repo: `embedded-hardware-portfolio`
